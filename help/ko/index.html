시작하기

AI Effect Video는 원본 영상 위에, 이펙트 영상에서 고른 영역을 크기 변환 없이 프레임 구간 단위로 복사해 덮어쓰고 새 영상으로 내보내는 편집기입니다. 글자·모자이크·클립아트·자막도 함께 넣을 수 있습니다.

기본 작업 순서

  1. 파일 › 원본 영상 열기…(Ctrl+O)로 원본을 엽니다. 영상 파일을 창에 끌어다 놓아도 됩니다.
  2. 파일 › 이펙트 영상 열기…(Ctrl+Shift+O)로 이펙트 영상을 엽니다. 크기가 달라도 됩니다.
  3. 타임라인에서 시작할 프레임으로 이동합니다.
  4. 작업영상 뷰어나 이펙트 뷰어에서 드래그해 영역을 그립니다. 그 프레임부터 영역이 적용됩니다.
  5. 끝낼 프레임으로 이동해 객체 목록의 [여기서 끝]을 누릅니다.
  6. 파일 › 프로젝트 저장(Ctrl+S)으로 저장하고, 파일 › 내보내기…(Ctrl+E)로 결과 영상을 만듭니다.

알아 두면 좋은 점

  • 파일 › 새 프로젝트(Ctrl+N)는 지금 작업을 닫고 처음 켠 상태로 돌아갑니다. 저장하지 않은 변경이 있으면 먼저 묻습니다.
  • 프로젝트 파일(.evproj)은 영상 파일의 경로와 편집 내용만 저장합니다. 영상을 옮기면 열 때 다시 찾기를 묻습니다.
  • 파일 › 최근 프로젝트에서 최근에 연 프로젝트를 바로 열 수 있습니다.
  • 저장하지 않은 작업은 설정 › 임시 백업 간격마다 임시 파일로 남습니다. 비정상 종료 후 다시 실행하면 복구할 수 있습니다.
  • 화면 언어는 설정 › 언어에서 바꿉니다.
