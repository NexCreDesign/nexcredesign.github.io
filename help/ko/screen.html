AI 연결: 설정 › AI 연결 허용을 켜면 Claude Desktop이 대화로 편집합니다.
2
작업영상 뷰어 — 원본 + 객체 합성 결과를 캐시 없이 실시간 표시. 드래그 = 새 객체 추가(여러 개 가능), Shift+드래그 = 선택 객체를 현재 프레임부터 다시 지정, 클릭 = 객체 선택. 선택 객체 안을 끌면 이동, 손잡이를 끌면 크기 조절. 도구줄 아이콘 [이펙트 영역 ▾]의 [다각형](P) = 클릭으로 꼭짓점, 첫 점·더블클릭·Enter·오른쪽 클릭으로 닫기(3점부터 완성 모양 미리보기), 선택한 다각형은 꼭짓점을 끌어 수정. [타원](O) = 드래그, 사각형처럼 크기 조절. [텍스트](T) = 클릭한 곳에 자막, 목록에서 글자·글꼴·크기·색. [모자이크](M) = 드래그로 원본 가리기. [클립아트] = 목록에서 골라 클릭·드래그로 놓기, Ctrl+V로 붙인 그림도 목록에 모임.
3
이펙트 영상 뷰어 — 싱크된 이펙트 원본과 같은 객체 테두리. 사용 중인 이펙트 프레임 번호·fps 표시. fps가 달라도 열 수 있으며 가장 가까운 프레임을 사용. 이펙트는 여러 개 열 수 있고 객체마다 고릅니다. 트랙은 이펙트 오디오처럼 자릅니다.
4
뷰어 도구줄 · 줌 — 뷰어마다 독립. 휠 = 커서 기준 확대(최대 800%, 1픽셀=8×8), 가운데 버튼 드래그 또는 키패드 4·6·8·2(좌·우·상·하, NumLock 무관, Shift=한 화면) = 이동. 1:1 실제 픽셀, 창 맞춤. 축소는 1:1 미만에서만 창 크기로 제한.
5
선택 객체 표시 — 선택 객체는 굵은 실선 + 모서리 핸들 + 이름표, 다른 객체는 점선. 목록·뷰어·타임라인 어디서 선택해도 두 뷰어에 동시 표시.
6
객체 목록 — 현재 프레임에 있는 객체만 표시. 구간이 끝나면 목록에서 사라지고, 시작 프레임에서 나타납니다. 이름 더블클릭 = 이름 변경.
7
좌표 숫자 입력 X·Y·W·H — 픽셀 단위로 정밀 수정, 현재 프레임부터 적용. 영상 밖으로 나가는 값은 자동 보정. 이펙트 위치는 복사해 올 자리(뷰어마다 끌기, Shift+끌기 = 양쪽 같은 거리), 블루스크린 투명이면 파란 배경은 원본이 비칩니다.
8
⇤ 구간 시작으로 — 이동 후 수정하면 구간 전체가 바뀝니다. [여기서 끝] = 현재 프레임부터 삭제(직전 프레임까지 유지), ⋯ = 구간 끝/첫 프레임 이동, 객체 전체 삭제.
9
재생 · 프레임 입력 · 소리 — Space 재생, ←→ 1프레임. 입력칸 Ctrl+G: 1234 절대, +10/-10 상대, mm:ss:ff 타임코드 → Enter로 정확히 이동. 스피커 아이콘 클릭 = 소리 끄기/켜기(끄면 사선), 옆 슬라이더 = 볼륨(마우스를 올리면 %, 0이면 음소거, 음소거 중 움직이면 해제).
10
이펙트 영역 On/Off E — 작업영상 도구줄 [창 맞춤] 옆. Off면 원본 + 테두리만 보여 확인용으로 비교. 미리보기 전용이며 내보내기는 항상 적용.
11
이펙트 오프셋 — 이펙트 도구줄 [창 맞춤] 옆 − 값 +. 이펙트 영상 시작 위치를 원본 프레임 단위로 싱크. [ ] 키 또는 타임라인 이펙트 막대 양 끝 손잡이를 드래그하거나 막대를 휠 버튼으로 드래그(막대의 나머지 부분 왼쪽 버튼은 프레임 이동).
12
타임라인 — 원본영상 아래 오디오 웨이브폼 줄(작은 소리 밝은 파랑 → 큰 소리 빨강, 안쪽 밝은 띠 = 평균 음량). 객체마다 한 줄(목록과 달리 모든 객체), 흰 마커 = 구간 시작. 원본/이펙트 트랙에 썸네일(보기 › 타임라인 썸네일). Alt+휠 = 객체 줄 세로 스크롤. ✂ 자르기 = 앞·뒤를 해치 무늬로 잘라 냄. 원본 오디오 스피커 = On/Off. 이펙트 오디오(여러 트랙, 맨 아래 칸 [＋] 0/현재 프레임에 추가) = 보라 손잡이(파일 시작·끝)로 오프셋, 막대 오른쪽 클릭 → 여기서 자르기(1초 뒤 새 구간), 구간 끌기·양 끝 조절, [⋯] 숫자.
13
현재 프레임 위치 선 — 눈금·빈 곳 클릭/드래그로 스크럽(현재 프레임을 바꾸는 유일한 타임라인 조작). 확대 시 현재 프레임 칸을 빨갛게 강조.
14
타임라인 확대 — Ctrl+휠 = 커서 기준 확대(최대 1프레임 40px, 프레임 칸 표시), 전체보다 축소 불가. 위 경계 끌기 = 높이(뷰어 반대로). 전체 보기, ⌖ 현재 프레임으로 Ctrl+L, 재생 시 따라가기.
15
좌우 스크롤바 — 확대 시에만 표시. 휠·스크롤바로 좌우 이동해도 현재 프레임은 그대로, 타임라인 화면만 움직입니다.
16
저장 안 됨 표시 ● — 저장하지 않은 변경이 있으면 종료·다른 프로젝트 열기 때 [저장] [저장 안 함] [취소]를 묻습니다.
17
뷰어 경계(스플리터) — 좌우로 드래그해 작업영상을 넓히면 이펙트 뷰어가 줄어듦. 오른쪽 끝까지 끌면 이펙트 뷰어 접기, 더블클릭 = 6:4.
18
창 분리 작업영상 창 분리 Ctrl+Shift+D — 작업영상을 별도 창으로 띄워 다른 모니터로 이동, F11 전체 화면. 창을 닫으면 다시 붙음. 분리 창에서도 객체 편집·단축키 그대로.
