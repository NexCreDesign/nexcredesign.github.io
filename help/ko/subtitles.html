자막

파일 › 자막 열기…로 SRT·VTT·ASS/SSA 파일을 불러옵니다. 파일을 창에 끌어다 놓아도 됩니다. UTF-8과 CP949(한국어 Windows 인코딩)를 읽습니다.

  • 자막은 작업영상 뷰어와 내보낸 영상에 그려집니다.
  • 모양은 고정입니다: 영상 높이의 5%, 흰 글자에 검정 외곽선, 아래 가운데. 자막 파일의 글꼴·색 설정은 쓰지 않습니다.
  • 긴 줄은 영상 폭의 90%에서 자동으로 줄을 바꿉니다. 겹치는 대사는 위로 쌓입니다.
  • 시간을 옮기려면 자막 트랙의 손잡이를 끌거나 [⋯] 메뉴, 객체 목록의 "자막" 항목에서 오프셋을 고칩니다.
  • 파일 › 자막 닫기로 뺍니다. 프로젝트에는 파일 경로와 오프셋이 저장됩니다.
