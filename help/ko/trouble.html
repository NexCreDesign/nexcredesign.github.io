문제 해결

자주 묻는 질문

재생이 끊기거나 화면이 깨집니다

설정 › 하드웨어 디코딩 (GPU)을 끄거나 켜 보세요. 지원하지 않는 영상은 자동으로 CPU로 디코딩합니다. 그래픽 드라이버 업데이트도 도움이 됩니다.

스크럽이 느립니다

키프레임 간격이 긴 영상은 임의 이동이 느릴 수 있습니다. 4K 영상에서 특히 그렇습니다.

"가변 프레임레이트 영상입니다" 안내가 뜹니다

휴대폰·화면 녹화 영상에 흔합니다. 평균 프레임레이트로 맞춰 각 프레임 시각의 화면으로 편집·내보내며 소리 싱크는 유지됩니다. 스마트 복사는 쓰이지 않습니다.

영상이 열리지 않습니다

3840×2160을 넘는 영상은 열 수 없습니다. 이펙트 영상도 같습니다.

내보내기에 쓸 인코더가 없습니다

그래픽 드라이버를 업데이트하고, Windows N 버전이면 미디어 기능 팩을 설치하세요. AV1·VP9는 CPU 인코더로도 내보낼 수 있습니다.

내보내기가 인코더 오류로 멈춥니다

실패 화면의 [다시 시도]로 다른 인코더를 써 보세요. 다른 프로그램이 그래픽 카드 인코더를 쓰고 있으면 실패할 수 있습니다.

소리가 나지 않습니다

Windows의 기본 출력 장치를 확인하세요. 원본 오디오 스피커 단추와 재생 줄의 음소거도 확인하세요.

프로그램이 비정상 종료됐습니다

다시 실행하면 임시 백업 목록이 나옵니다. 복구할 작업을 고르거나 필요 없는 것을 지우세요. 7일이 지난 백업은 자동으로 지워집니다. 문의할 때는 도움말 › 로그 저장…으로 만든 파일을 보내 주세요. 도움말 › 로그 폴더 열기에는 비정상 종료 기록이 있습니다. 로그는 이 PC에만 남습니다.
