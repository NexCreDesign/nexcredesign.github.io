Getting Started

AI Effect Video overlays regions copied from an effect video onto a source video without resizing them, frame range by frame range, and exports the result as a new video. You can also add text, mosaics, clip art and subtitles.

Basic workflow

  1. Open the source with File › Open Source Video… (Ctrl+O), or drag a video file onto the window.
  2. Open the effect video with File › Open Effect Video… (Ctrl+Shift+O). Its size may differ from the source.
  3. Move to the frame where the region should start on the timeline.
  4. Drag in the work viewer or the effect viewer to draw a region. It applies from that frame on.
  5. Move to the last frame and press [End here] in the object list.
  6. Save with File › Save Project (Ctrl+S) and make the video with File › Export… (Ctrl+E).

Good to know

  • File › New Project (Ctrl+N) closes the current work and returns to the state at startup. If there are unsaved changes, it asks first.
  • A project file (.evproj) stores the paths of your videos and your edits only. If you move a video, the app asks you to find it again.
  • File › Recent Projects opens a project you used recently.
  • Unsaved work is saved to a temporary backup at the interval set in Settings › Temporary Backup. After a crash, the next start offers to restore it.
  • Change the display language in Settings › Language.
