Subtitles

Load an SRT, VTT or ASS/SSA file with File › Open Subtitles…, or drag it onto the window. UTF-8 and CP949 (Korean Windows encoding) are supported.

  • Subtitles are drawn in the work viewer and in the exported video.
  • The look is fixed: 5% of the video height, white text with a black outline, bottom center. Font and color settings in the file are not used.
  • Long lines wrap at 90% of the video width, and overlapping lines stack upward.
  • To shift the timing, drag the handle on the subtitle track, or change the offset in its [⋯] menu or the "Subtitles" entry in the object list.
  • File › Close Subtitles removes them. The project stores the file path and offset.
