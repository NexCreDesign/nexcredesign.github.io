Effect Video and Sync

Effect video requirements

  • The resolution may differ from the source. The effect video is used without resizing, and you work in source coordinates. Any part of an object outside the effect shows the source.
  • The frame rate may differ. The app tells you and uses the effect frame closest in time to each frame.

Several effect videos

You can open as many effect videos as you like, with the button at the bottom of the timeline or File › Open Effect Video….

  • Each object uses one effect. A new object uses the effect shown in the effect viewer. Change it in the "Effect" box in the object list.
  • There is one effect viewer. Switch it with the box above it or by clicking a track name on the timeline. Selecting an object switches to that object's effect.
  • Each effect has its own offset, and the offset controls apply to the shown effect.
  • Close an effect from the track's [⋯] menu. Objects that use it stay, and show the source until you pick another effect.

Cutting an effect video

This works like effect audio. Right-click the track to cut, drag a section to move it, and drag its edge to change its length. Objects using that effect show the source where it is cut.

Effect position of an object

The effect video does not move. Instead, each object can copy from its own effect position. See Objects.

Offset

The offset is the work frame where frame 0 of the effect video sits.

  • [ and ] change it one frame at a time.
  • Type a number in the offset box on the effect viewer toolbar, or use the − and + buttons.
  • You can also drag the effect video track on the timeline.

FX #number above the effect viewer is the frame number in the effect video. If there is no matching frame, the viewer shows that it is out of range and regions there export as the plain source.
