1
Menu — Open source Ctrl+O, open effect Ctrl+Shift+O, add effect audio Ctrl+Alt+O (+Shift: current frame), save project Ctrl+S, Edit › Undo / Edit › Redo Ctrl+Z / Ctrl+Y (object and offset edits), File › Export… Ctrl+E (default file name sourcename_ev.mp4), quit Ctrl+Q. Settings › Language switches 한국어 / English instantly; Settings › Hardware Decoding (GPU) (GPU, on by default); Help › About AI Effect Video… (version, open source licenses). Open Subtitles = SRT/VTT/ASS. Drop a file = open. Open the source first. AI connection: with Settings › Allow AI connection on, Claude Desktop edits by chat.
2
Work video viewer — Source + composited objects, live with no cache. Drag = add a new object (as many as you like), Shift+drag = redraw the selected object from the current frame, click = select an object. Drag inside the selected object to move it, drag its handles to resize. Toolbar icon menu [Effect region ▾] › [Polygon] (P) = click points, close with the first point, double-click, Enter or right-click (closed shape previewed from 3 points); drag a selected polygon's points to reshape it. [Ellipse] (O) = drag; resize like a rectangle. [Text] (T) = click to place a caption; edit text, font, size, color in the list. [Mosaic] (M) = drag to hide the source. [Clip art] = pick from the list, click or drag to place; pictures pasted with Ctrl+V join the list.
3
Effect video viewer — The synced effect video with the same object outlines. Shows the effect frame in use and its fps. A different fps is allowed; the nearest frame is used. Open several effects and pick one per object; cut their tracks like effect audio.
4
Viewer toolbar · zoom — Independent per viewer. Wheel = zoom at the cursor (up to 800%, 1 pixel = 8×8), middle-drag or keypad 4·6·8·2 (left·right·up·down, any NumLock, Shift = one screen) = pan. 1:1 actual pixels, Fit. Zooming out stops at the window size only below 1:1.
5
Selected object — Thick solid line + corner handles + name tag; other objects are dashed. Selecting in the list, a viewer or the timeline shows it in both viewers.
6
Object list — Shows only objects on the current frame. An object disappears after its range ends and appears at its start frame. The frame range is on the line under the name. Double-click the name = rename.
7
X·Y·W·H fields — Precise pixel edits, applied from the current frame. Values outside the video are corrected automatically. Effect position is where to copy from (drag in each viewer; Shift+drag moves both the same distance). With Blue screen transparent the source shows through the blue background.
8
⇤ Go to segment start — Edits made there change the whole segment. [End here] = delete from the current frame (kept up to the previous frame), ⋯ = go to segment end / first frame, delete the entire object.
9
Playback · frame input · sound — Space play, ←→ 1 frame. Field Ctrl+G: 1234 absolute, +10/-10 relative, mm:ss:ff timecode → Enter jumps exactly. Speaker icon = mute/unmute (slash when muted), slider = volume (hover shows %, 0 mutes, moving it while muted unmutes).
10
Effect regions On/Off E — Next to [Fit] on the work video toolbar. Off shows the source + outlines only, for comparison. Preview only; export always applies objects.
11
Effect offset — − value + next to [Fit] on the effect toolbar. Syncs the effect start in source frames. Also [ ] keys or drag the effect bar's end handles, or the bar itself with the wheel (middle) button (left-clicking elsewhere on the bar moves the frame).
12
Timeline — Audio waveform row under Source (quiet = light blue → loud = red, bright inner band = average loudness). One row per object (unlike the list, all objects), white marker = segment start. Source/Effect tracks show thumbnails (View › Timeline Thumbnails). Alt+wheel = scroll object rows vertically. ✂ Cut start/end. Speaker = source on/off. Effect audio (many, add with [＋]): grips = offset, right-click → Cut Here.
13
Playhead — Click/drag the ruler or empty space to scrub (the only timeline action that changes the current frame). When zoomed in, the current frame cell is highlighted red.
14
Timeline zoom — Ctrl+wheel = zoom at the cursor (up to 40px per frame, frame cells shown), never smaller than the whole. Drag the top edge = height. Fit All, ◎ go to current frame Ctrl+L, follow playback.
15
Horizontal scrollbar — Shown only when zoomed in. Scrolling with the wheel or the bar keeps the current frame; only the timeline view moves.
16
Unsaved mark ● — With unsaved changes, quitting or opening another project asks [Save] [Don't Save] [Cancel].
17
Viewer splitter — Drag left/right; widening the work video shrinks the effect viewer. Right edge = collapse, double-click = 6:4.
18
Detach work video window Ctrl+Shift+D — Opens the work video in its own window to move to another monitor, F11 full screen. Closing it re-attaches. Object editing and shortcuts work there too.
