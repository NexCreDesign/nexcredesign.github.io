Objects

Effect regions (rectangle, polygon, ellipse)

These copy the same area of the effect video onto the work video. You can draw them in either viewer.

  • R rectangle, O ellipse: drag to draw.
  • P polygon: click to place vertices. Close it by clicking the first vertex, pressing Enter or right-clicking. Backspace removes the last vertex and Esc cancels.
  • Shift+drag outside the selected object redefines that region from the current frame.

Two positions

An effect region has one size and two positions. The work position is where the result goes. The effect position is where it is copied from.

  • Dragging moves only that viewer's position. Drag in the work viewer to change where the result goes, and in the effect viewer to change where it is copied from.
  • Shift+drag inside the selected object moves both by the same distance. If one side reaches its edge, both stop.
  • The size is always the same in both, whichever viewer you resize it in.
  • Type values in the "Effect position" X and Y boxes in the object list, or use [Match work position] to use the same coordinates.
  • Any part with no effect pixel to copy shows the source.

Blue screen

Turn on "Blue screen transparent" in the object list to skip the effect's blue background, so the source shows through. It is set per object. Soft edges such as fire or smoke blend naturally with the source. Blue objects are removed too, and purple or magenta can disappear or fade.

Text, mosaic and clip art

These are created in the work viewer only and do not need an effect video.

  • T text: click an empty spot. Change the content, size, color, font and outline color in the object list.
  • M mosaic: drag a box to hide the source under blocks.
  • Clip art: open the list with the clip art button on the toolbar, pick an image and place it. Pictures copied from PowerPoint and similar apps paste with Ctrl+V, keeping transparency. Edit › Add Clip Art from Image File… also works.

Drawing order: mosaic → effect regions → clip art → text → subtitles.

Selecting and editing

  • Click an object or pick it in the list. Tab and Shift+Tab step through the objects on the current frame.
  • Drag inside to move and drag a handle to resize. Polygon vertices can be dragged too.
  • You can also type X, Y, W and H values in the list.

Range rules

Edits apply from the current frame on; earlier frames stay as they are. To change a whole range, go to its start with the ⇤ button in the list, then edit.

  • The effect position also follows ranges. Where objects of the same kind overlap, the lower one in the list is drawn on top.
  • [End here] or Delete ends the selected object at the current frame.
  • Shift+Delete removes the whole object.
  • Right-click an object bar on the timeline to remove a change point.
  • The eye button hides an object. Hidden objects are not exported. Drag the handle in the list to change the order.
  • E or the On/Off switch only turns compositing off in the preview. It does not change the export.
  • Ctrl+Z undoes and Ctrl+Y redoes.
